# Observatório Sócrates

Infraestrutura local-first para coleta, análise comparativa e revisão humana de cobertura esportiva pública sobre o S.C. Corinthians Paulista.

## Princípios

- Evidência antes de interpretação.
- Conteúdo público, fonte preservada e contexto verificável.
- IA sugere; pessoas revisam e decidem.
- Coleta e triagem podem ser automatizadas; publicação nunca é automática.
- Dados e serviços permanecem locais por padrão.

## Estado inicial

Este repositório contém apenas documentação e contratos de configuração. Nenhuma credencial, automação, crawler, transcrição ou publicação é ativada nesta etapa.

## Estrutura

- `docs/` — decisões, método e segurança.
- `infra/` — contratos de configuração para Docker e n8n.
- `data/` — diretórios locais ignorados pelo Git para dados de trabalho.

Consulte `docs/01-visao-e-escopo.md` antes de implementar qualquer coleta.
