# Método de evidências

Cada alegação analítica deve apontar para fontes públicas originais e conter:

1. identificação do emissor, canal, data e URL;
2. trecho literal curto ou transcrição com marcação de tempo;
3. tema e caso comparado;
4. justificativa de comparabilidade;
5. avaliação humana do contexto completo;
6. conclusão limitada ao que as evidências sustentam.

Uma diferença de opinião isolada não é evidência suficiente. O sistema deverá distinguir fato, opinião, hipótese e retórica.
