# Ficha de cadastro manual — contrato do MVP

Preencher esta ficha antes de qualquer análise. Campos entre colchetes são valores controlados.

```yaml
fonte:
  source_id: SRC-0001
  nome_publico: ""
  tipo: "[canal_institucional|profissional_individual|texto_publico]"
  url_base: "https://"
  justificativa_de_inclusao: ""
  status: "proposta"
  revisor: ""
  data_de_cadastro: "AAAA-MM-DD"

item:
  item_id: ITM-0001
  source_id: SRC-0001
  url_canonica: "https://"
  titulo: ""
  publicado_em: "AAAA-MM-DDTHH:MM:SS-03:00"
  capturado_em: "AAAA-MM-DDTHH:MM:SS-03:00"
  formato: "[video|podcast|artigo|postagem_publica]"
  tema: ""
  clubes_mencionados: []
  transcricao_origem: "[manual|fonte|modelo_local]"
  hash: ""

revisao:
  contexto_consultado: false
  caso_comparavel: ""
  justificativa_de_equivalencia: ""
  decisao: "[descartar|complementar_contexto|sem_evidencia_suficiente|aprovar_dossie_privado]"
  justificativa: ""
```

Uma ficha incompleta pode existir como rascunho, mas não entra na fila de comparação.
