# ADR 0002 — MVP manual primeiro

## Status

Aceita — 2026-09-13

## Decisão

O MVP começa com fontes e evidências cadastradas manualmente. Modelos locais podem estruturar texto, mas a seleção de casos e a conclusão comparativa exigem revisão humana.

## Motivo

O problema é interpretativo e sensível a contexto. Validar o método antes de automatizar reduz falsos positivos, coleta excessiva e conclusões injustas.
