# ADR 0003 — Protocolo de fontes neutro e amostragem limitada

## Status

Aceita — 2026-09-13

## Decisão

O projeto cadastra fontes por relevância metodológica, não por suposta posição em relação ao Corinthians. O MVP opera com amostras pequenas, janela temporal explícita e exigência de caso comparável.

## Consequência

O ritmo inicial é deliberadamente mais lento, mas os resultados são mais auditáveis, menos vulneráveis a seleção enviesada e mais adequados para um portfólio responsável.
